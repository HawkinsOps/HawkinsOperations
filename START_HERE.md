# Start Here

For recruiters and hiring managers. No tools required. Total time: ~5 minutes.

## What this project is

A live detection and triage pipeline built on self-hosted infrastructure. The system ingests security alerts from a 10-agent Wazuh deployment, triages them automatically, and produces verifiable proof artifacts. Everything documented here runs on real infrastructure — not slides, not diagrams, not plans.

Built from zero experience in 7 months while working mandatory 12-hour shifts.

## What the CI checks verify

Every pull request runs automated checks before merge:

| Check | What it does |
| --- | --- |
| **verify** | Counts all detection rules, generates site data, builds Wazuh bundle, validates hosting |
| **drift-scan** | Compares published counts against actual files — fails if any number drifts |
| **contract-scan** | Blocks accidental commits of runtime data or oversized files |

These are required to pass before any change merges to `main`.
