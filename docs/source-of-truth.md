# Source Of Truth

## Purpose

This file defines the governing public narrative for HawkinsOperations.

If future copy, plans, or page drafts conflict with this file, this file wins unless it is explicitly updated.

## Core identity

Raylee Hawkins is an early-career cybersecurity operator focused on:
- SOC analysis
- detection engineering
- security automation

This is not a reinvention-from-zero story. It is an operations-to-security transition.

## Cyber-first rule

The site stays cybersecurity-first.

Manufacturing experience is supporting evidence for:
- operating under pressure
- escalation judgment
- SOP discipline
- quality control
- documentation habits
- systems thinking

Manufacturing experience should strengthen the cyber story, not replace it.

## Flagship rule

`SignalFoundry` is the flagship public proof object.

The site should make it easy for a reviewer to understand:
- what SignalFoundry is
- what it does
- what outcomes are verified
- where to go next for proof

## Identity boundaries

- `HawkinsOperations` is the site and umbrella portfolio identity.
- `SignalFoundry` is the flagship system.
- `AutoSOC` is the engine and historical implementation term where technically useful.

Do not collapse all three names into one undifferentiated label.

## Reviewer trust rule

- If a claim cannot be traced to committed proof, it does not belong on the site.
- If a number drifts across surfaces, the number is wrong until reconciled.
- Proof density matters more than marketing polish.

## Positioning rule

The strongest public framing is:

An operations-minded security candidate who built, ran, debugged, and documented a functioning SOC-style pipeline with measurable outputs and public-safe proof.

Avoid weaker framing such as:
- generic beginner
- AI enthusiast
- founder-style personal brand
- vague automation evangelist

## Splunk rule

Splunk belongs in the story only to the level supported by committed proof.

Current supported level:
- live Windows telemetry ingest exists
- Event ID 4688 pivots are validated

Claims beyond that require newer proof artifacts.

## Narrative goals for the site

Within the first minute, a reviewer should be able to answer:
- Who is this?
- What kind of security work does she do?
- What is the flagship proof object?
