## Deploy Steps (Linux Splunk Host)

0. Ensure SMB source is mounted to `/mnt/operations`.

```bash
sudo mkdir -p /mnt/operations
sudo mount -t cifs //REDACTED_SERVER/Operations /mnt/operations \
  -o username=REDACTED_USER,password=REDACTED_PASS,vers=3.0,uid=$(id -u),gid=$(id -g)
sudo ls -lah /mnt/operations
```

Persistent mount option (`/etc/fstab` entry):

```fstab
//REDACTED_SERVER/Operations /mnt/operations cifs username=REDACTED_USER,password=REDACTED_PASS,vers=3.0,iocharset=utf8,uid=1000,gid=1000,_netdev 0 0
```

Use a credentials file in production instead of inline credentials.

1. Create a backup of current local app config.

```bash
sudo cp -a /opt/splunk/etc/apps/search/local /opt/splunk/etc/apps/search/local.bak_03-19-2026
```

2. Copy repo config files to Splunk app local path.

```bash
sudo cp content/lab/proxmox/vms/104/splunk/local/inputs.conf /opt/splunk/etc/apps/search/local/inputs.conf
sudo cp content/lab/proxmox/vms/104/splunk/local/props.conf /opt/splunk/etc/apps/search/local/props.conf
sudo cp content/lab/proxmox/vms/104/splunk/local/transforms.conf /opt/splunk/etc/apps/search/local/transforms.conf
```

3. Validate config through btool.

```bash
sudo /opt/splunk/bin/splunk btool inputs list --debug | grep -E "monitor:///mnt/operations|XmlWinEventLog:Security"
sudo /opt/splunk/bin/splunk btool props list XmlWinEventLog:Security --debug
sudo /opt/splunk/bin/splunk btool transforms list xml4688_eventid --debug
```

4. Restart Splunk.

```bash
sudo /opt/splunk/bin/splunk restart
```

```spl
| rex field=_raw "(?ms)<EventID>\s*(?<EventID>\d+)\s*</EventID>"

```
